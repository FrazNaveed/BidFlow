# Meridian Advisory & Technology — Company Library

These are **realistic proposal documents** (plain text for indexing). Replace names, figures, and project details with your actual company before production use.

## Documents

| File | Purpose |
|------|---------|
| `01-company-profile.txt` | Legal entity, offices, leadership, insurance |
| `02-services-and-capabilities.txt` | Service lines and delivery methodology |
| `03-case-study-business-plan-incubator.txt` | Business plan / incubator work (Karandaz-style) |
| `04-case-study-provincial-procurement-portal.txt` | Public-sector IT / e-procurement |
| `05-case-study-logistics-fleet-analytics.txt` | Logistics / data analytics |
| `06-compliance-and-policies.txt` | ISO, security, ethics, insurance |
| `07-key-personnel.txt` | CV summaries for key bid staff |

## Structured data (database only)

| File | Purpose |
|------|---------|
| `bid-history.json` | 12 past bids — powers win-rate and budget alignment scoring |
| `capability-index.json` | Project metadata matching the three case studies |

## How to use in the app

1. Open **Library** → **Index company library**
2. Upload incoming tenders via **Analyze**

To customize: edit the `.txt` files, update JSON if project metadata changes, then re-index.
